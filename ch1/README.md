# 챕터 1 · 변동성 이론

**우리나라 주식시장의 변동성 분해 — 연구실 해설** — 「우리나라 주식시장의 변동성 분해 분석 : 산업별·기간별 변동성 분해 분석과 수익률 효과 분석」 해설 · 글 · 안상선 ((주)M-Robo 대표)

![챕터 그림](img/thumb.jpg)

*논문 1장 서론 일부와 2장 이론적 배경(pp.1-38)*

주가 수익률은 맞히기 어렵지만, 출렁임(변동성)은 뭉쳐서 오고 어느 정도 예측된다. 챕터 1은 논문이 실증에 쓰는 도구를 차례로 쌓는다. 시계열의 얼굴과 효율적 시장가설에서 출발해 위험 측정(VaR·이동평균), 변동성 군집과 ARCH 효과 검정, ARCH·GARCH 계열, 비대칭 모형과 지속·일시 변동성 분해, 마지막으로 시장의 예상을 담은 변동성 지수까지 간다.

숫자 가운데 원문 표·그림의 값은 각 쪽의 출처 번호로 확인할 수 있습니다. 논문 PDF의 부록에는 일별 원자료가 실려 있지 않아(자료 출처만 기재), 그림과 실험은 논문이 추정한 모수(GARCH α 0.091, β 0.901, 장기 일일 σ 1.69%)로 만든 설명용 모의 시장입니다. KRX 원자료를 받으면 실제 자료로 바꿀 수 있습니다.
