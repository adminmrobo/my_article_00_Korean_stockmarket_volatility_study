# 챕터 3 · 실증 결과와 결론

**우리나라 주식시장의 변동성 분해 — 연구실 해설** — 「우리나라 주식시장의 변동성 분해 분석 : 산업별·기간별 변동성 분해 분석과 수익률 효과 분석」 해설 · 글 · 안상선 ((주)M-Robo 대표)

![챕터 그림](img/thumb.jpg)

*논문 5장 실증 분석, 6장 결론, 영문 초록, 부록(pp.101-249)*

챕터 3은 논문의 실증 결과를 원문 표 그대로 펼친다. GARCH-M으로 잰 변동성과 위험 프리미엄(표 5.1), 지속·일시 변동성으로의 분해(표 5.2, 그림 5.1~5.3), 분해 검증과 Chow 검정, 섹터별 기여도(표 5.3), 그리고 VKOSPI·달러선물·KOSPI200선물의 수익률 효과(표 5.4, 회귀 108개)를 차례로 본다. 각 페이지는 원문 표 열람기와 본문·결론 문장 대조를 함께 싣고, 마지막 3-7에서 결론 지도와 정오표, 원자료로 다시 낼 순서를 정리한다.

## 읽기 전에

표·열지도·대조표의 숫자는 원문 표 5.1.1~5.4.109의 실제 값입니다(3인 분담 전사 후 대조). 일별 원자료는 PDF에 없어, 경로 그림은 원문 그림 5.1~5.5를 300dpi로 렌더해 픽셀로 읽은 근사 계열(약 400점, 2.5거래일 간격)이고 화면에 '그림 근사'로 표시했습니다. 실험과 대결은 설명용 모의 자료입니다. 결론·요약 문장 가운데 같은 장의 표와 다른 곳(USDF 자유소비재·철강소재 등)은 3-6과 3-7에 근거와 함께 정리했습니다.
