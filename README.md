# 우리나라 주식시장의 변동성 분해 분석
### 산업별·기간별 변동성 분해 분석과 수익률 효과 분석

**우리나라 주식시장의 변동성 분해 — 연구실 해설** · 글 · 안상선 ((주)M-Robo 대표)

![표지](img/cover.jpg)

2012년 박사학위논문을 연구실 네 캐릭터와 함께 다시 읽는 인터랙티브 해설 시리즈입니다. 챕터 3개, 해설 20쪽으로 이론 → 연구 설계 → 실증 결과와 결론을 차례로 다룹니다.

👉 **[표지 열기 (index.html)](index.html)**

## 세 가지 연구 질문

1. 섹터별 변동성은 어떻게 생겼고, 오래 남는 몫(지속적 변동성)과 금방 사라지는 몫(일시적 변동성)으로 어떻게 나뉘나 — GARCH-M(1,1), 상태공간모형·칼만 필터, Chow 검정
2. 전체시장의 변동성에 어느 산업이 얼마나 기여했나 — 기여도 회귀
3. 시장의 기대(VKOSPI·달러선물·KOSPI200선물)가 다음 날 섹터 수익률을 움직였나 — 수익률 효과 모형 1~3, 회귀표 108개

## 챕터 1 · 변동성 이론

[![챕터 1](ch1/img/thumb.jpg)](ch1/index.html)

*논문 1장 서론 일부와 2장 이론적 배경(pp.1-38)* · [목차](ch1/index.html)

주가 수익률은 맞히기 어렵지만, 출렁임(변동성)은 뭉쳐서 오고 어느 정도 예측된다. 챕터 1은 논문이 실증에 쓰는 도구를 차례로 쌓는다. 시계열의 얼굴과 효율적 시장가설에서 출발해 위험 측정(VaR·이동평균), 변동성 군집과 ARCH 효과 검정, ARCH·GARCH 계열, 비대칭 모형과 지속·일시 변동성 분해, 마지막으로 시장의 예상을 담은 변동성 지수까지 간다.

| 쪽 | 제목 | 질문 |
|---|---|---|
| [1-1](ch1/1-1_time-series.html) | 시계열 데이터의 얼굴 | 주가 그래프를 그대로 분석하면 안 되는 이유는 무엇일까? |
| [1-2](ch1/1-2_efficient-market.html) | 효율적 시장가설 | 과거 주가로 내일의 방향을 맞혀 꾸준히 돈을 벌 수 있을까? |
| [1-3](ch1/1-3_risk-measures.html) | 위험 측정 | 내일 잃을 수 있는 돈을 숫자 하나로 말할 수 있을까? |
| [1-4](ch1/1-4_clustering-tests.html) | 변동성 군집과 검정 | 출렁임이 정말 몰려오는지, 숫자로 어떻게 확인할까? |
| [1-5](ch1/1-5_arch-garch.html) | ARCH와 GARCH | 몇 개의 숫자만으로 출렁임의 기억을 식으로 쓸 수 있을까? |
| [1-6](ch1/1-6_asymmetry-decomposition.html) | 비대칭과 분해 | 같은 크기의 충격인데 왜 나쁜 뉴스가 더 오래 흔들까, 그리고 그 흔들림은 어디까지가 진짜일까? |
| [1-7](ch1/1-7_volatility-index.html) | 변동성 지수 | 과거 자료가 아니라 시장의 '예상'으로 출렁임을 잴 수 있을까? |

## 챕터 2 · 연구 설계와 데이터

[![챕터 2](ch2/img/thumb.jpg)](ch2/index.html)

*논문 1장 서론, 3장 선행연구, 4장 연구 모형(pp.1-6, 39-100)* · [목차](ch2/index.html)

챕터 2는 논문이 무엇을, 어떻게, 언제 보았는지를 정리한다. 선행연구의 지도에서 빈칸(섹터지수 변동성 분해)을 찾고, KOSPI200 섹터지수 8개와 세 가지 연구 질문을 세운다. 질문마다 식(GARCH-M, 상태공간 분해, 기여도 회귀, 수익률 효과 모형)을 정하고, 1,245일을 네 기간으로 나눈 근거를 Chow 검정으로 확인한다. 마지막 두 쪽은 원문 표 4.4~4.27의 실제 숫자, 기초통계량·Ljung-Box Q·상관 행렬을 직접 펼치고 검산한다.

| 쪽 | 제목 | 질문 |
|---|---|---|
| [2-1](ch2/2-1_literature-map.html) | 선행연구 지도 | 앞선 연구들은 무엇을 밝혔고, 무엇이 비어 있었나? |
| [2-2](ch2/2-2_sector-questions.html) | 섹터지수와 연구 질문 | 왜 시장 전체가 아니라 섹터지수를 보았고, 무엇을 물었나? |
| [2-3](ch2/2-3_research-model.html) | 연구 모형 | 세 질문에 답하려면 어떤 식을 어떤 순서로 세워야 하나? |
| [2-4](ch2/2-4_periods-chow.html) | 표본 4기간과 Chow | 금융위기 전후를 한 표본으로 섞어도 될까? |
| [2-5](ch2/2-5_descriptive-stats.html) | 기초통계량 | 업종과 기간마다 수익률의 모양은 어떻게 다르고, 원문 숫자는 서로 맞을까? |
| [2-6](ch2/2-6_independence-correlation.html) | 독립성 검정과 상관 구조 | 오늘 수익률은 어제를 닮고, 업종들은 서로를 닮는가? |

## 챕터 3 · 실증 결과와 결론

[![챕터 3](ch3/img/thumb.jpg)](ch3/index.html)

*논문 5장 실증 분석, 6장 결론, 영문 초록, 부록(pp.101-249)* · [목차](ch3/index.html)

챕터 3은 논문의 실증 결과를 원문 표 그대로 펼친다. GARCH-M으로 잰 변동성과 위험 프리미엄(표 5.1), 지속·일시 변동성으로의 분해(표 5.2, 그림 5.1~5.3), 분해 검증과 Chow 검정, 섹터별 기여도(표 5.3), 그리고 VKOSPI·달러선물·KOSPI200선물의 수익률 효과(표 5.4, 회귀 108개)를 차례로 본다. 각 페이지는 원문 표 열람기와 본문·결론 문장 대조를 함께 싣고, 마지막 3-7에서 결론 지도와 정오표, 원자료로 다시 낼 순서를 정리한다.

| 쪽 | 제목 | 질문 |
|---|---|---|
| [3-1](ch3/3-1_garch-m-risk-premium.html) | GARCH-M과 위험 프리미엄 | 변동성이 커진 날, 시장은 그만큼 더 높은 수익률로 보상했을까? |
| [3-2](ch3/3-2_volatility-decomposition.html) | 관측·지속·일시 변동성 | 변동성 가운데 오래 남는 몫과 금방 사라지는 몫은 어떻게 생겼을까? |
| [3-3](ch3/3-3_decomposition-check.html) | 기간별 분해 검증 | 지속적 변동성이 일시적 변동성보다 관측변동성에 더 큰 영향을 주었을까? |
| [3-4](ch3/3-4_sector-contribution.html) | 섹터 기여도 | 시장 변동성에 가장 크게 기여한 산업은 어디였을까? |
